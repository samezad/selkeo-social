# selkeo-social

Images for Selkeo's social media posts. A scheduling tool fetches them from here by public URL.

- `en/<post>/NN.jpg`: the English posts, 1080×1350, one folder per post, images in carousel order.
- `en/posts.json`: each post's caption and the alt text of every image.

Post codes match the design canvas: `1`, `2`, `a`–`d` are carousels, `f`–`n` are single posts (`m` has two images).

Everything here is public. Do not add anything that is not meant to be published.
